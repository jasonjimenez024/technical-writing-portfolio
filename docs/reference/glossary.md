# Glossary

**API (Application Programming Interface)**
A defined set of rules that allows two pieces of software to communicate. You send a request, the API returns data.

**Endpoint**
A specific URL that performs one function within an API. Different endpoints return different types of data.

**API key**
A unique string of characters tied to your account that proves you are authorized to use the API.

**Authentication**
The process of verifying that a request includes a valid API key before returning data.

**JSON (JavaScript Object Notation)**
A structured text format used to organize and transmit data between a server and a client. Uses key-value pairs wrapped in curly braces.

**HTTP request**
A message sent to a server asking it to perform an action. GET requests retrieve data without modifying anything.

**Parameters**
Options added to a request URL that tell the API what data to return. Appended after a `?` and separated by `&`.

**Rate limiting**
A cap on the number of requests an account can make within a given time period. Exceeding the limit returns a 429 error.

**curl**
A command-line tool for making HTTP requests directly from a terminal without a browser or visual interface.

**Response**
The data the API returns after processing a request. Includes a status code indicating success or failure and a JSON body containing the requested data.
